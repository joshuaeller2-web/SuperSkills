# Sub-master: Assignment Dispatch

Use for intake, task allocation, dependency control, and follow-through.

## Minor methods

- **Intake shaping:** turn a request into objective, scope, deliverable, evidence, authority, and deadline.
- **Capability matching:** choose the narrowest role whose charter directly owns the deliverable.
- **Task dispersion:** split only independent bounded units; name owner, input, output, dependency, and return path for each.
- **Dependency control:** record prerequisites and block only the dependent work.
- **Capacity gate:** default to two specialists and one delegation level unless evidence justifies more.
- **Follow-through:** identify stalled work, cause, next owner, and concrete restart condition.
