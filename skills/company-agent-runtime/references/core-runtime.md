# Master: Agent Core Runtime

Runs for every authorized Company OS assignment.

## Minor methods

- **Agent lean context:** read the packet, charter, mapping entry, and directly relevant files once; reread changed files and final evidence. Put large output in the assignment folder. Checkpoint at 20 turns or 10 files.
- **Assignment contract:** preserve goal, allowed paths and actions, deliverable, budget, acceptance checks, and next owner as separate fields.
- **Bounded skill routing:** select one primary shared skill for domain work and at most one supporting shared skill. Agent-only methods govern coordination and evidence.
- **Evidence ledger:** label fresh observation, prior claim, simulation, UNAVAILABLE, BLOCKED, and WITHHELD distinctly.
- **Completion packet:** return changed artifacts, exact checks and exits, unresolved items, and next responsible role.

Do not load every role, sub-master, or source. Do not recursively activate the organization.
