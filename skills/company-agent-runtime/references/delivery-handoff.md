# Sub-master: Delivery and Handoff

Use for scoped implementation, review preparation, acceptance criteria, artifacts, and cross-agent transfer.

## Minor methods

- **Smallest useful increment:** implement the narrowest change that satisfies named acceptance.
- **Acceptance design:** give each requirement an identifier, observation, verdict, and evidence path.
- **Self-check:** verify the author-controlled checks without calling them independent acceptance.
- **Defect package:** return a reproducible symptom and bounded evidence to the original implementer.
- **Cross-agent handoff:** include goal, scope, decisions, artifacts, evidence, unresolved items, and next owner.
- **Closeout reconciliation:** compare delivered scope with accepted scope and record withheld work.
