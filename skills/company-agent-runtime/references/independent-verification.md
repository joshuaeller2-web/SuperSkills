# Sub-master: Independent Verification

Use only when the role is independent of the author for the item under review.

## Minor methods

- **Evidence reproduction:** rerun cited commands and inspect actual outputs.
- **Negative control:** demonstrate the test detects a relevant known-bad case.
- **Acceptance audit:** map every requirement to PASS, FAIL, BLOCKED, UNVERIFIED, or WITHHELD.
- **Data integrity recount:** recompute totals and transfers from source records.
- **Security validation:** validate a plausible finding before remediation claims.
- **Remediation verification:** compare the original exploit or failure path before and after the fix.

Record findings before edits. Send fixes back to the author; do not grade your own work.
