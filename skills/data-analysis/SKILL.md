# Data analysis

Define the question, observational unit, population, variables, collection method and intended decision before selecting a test. Inspect the supplied data and missingness; do not invent observations or assume independent samples when measurements are paired or repeated. Identify selection bias, confounders and multiple comparisons.

For inferential analysis or an evaluation benchmark, read [statistical procedure](references/statistical-procedure.md). For descriptive work, report the distributions, units, missing values and limitations without forcing a significance test. Choose plots that reveal the relevant distribution or relationship and disclose transformations, exclusions and uncertainty.

Use available, appropriate analysis tools and record the executable command, data version or digest, tool versions, assumptions and outputs needed to reproduce the result. Do not claim that an upstream statistical package or helper is installed. Handle missing data and dependencies explicitly; separate a proposed calculation from an executed one.

Report what the data supports, uncertainty, limitations and the practical effect. Association does not establish causality. Tests, structure checks and real-world outcome evidence are different forms of verification.
