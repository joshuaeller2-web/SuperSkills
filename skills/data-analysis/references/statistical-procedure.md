# Statistical procedure

1. Select the estimand and analysis from the question and design: independent versus paired observations, response type, sample size and repeated measurements. State the null and alternative only when a hypothesis test serves the decision.
2. Inspect assumptions with suitable diagnostics. Check distribution, dependence and variance assumptions where the chosen method requires them. Explain a robust, transformed, resampling or nonparametric alternative when appropriate; do not mechanically replace a test after a single diagnostic p-value.
3. Report effect sizes and confidence or credible intervals with their definitions. A p-value is evidence conditional on the model and assumptions, not proof that an effect exists, its size, or the probability a hypothesis is true.
4. For a planned study, justify sample size using a meaningful effect, variability, error rates and design. For completed studies, emphasize interval precision and sensitivity; do not use observed post-hoc power as independent evidence.
5. Document exclusions, missing-data treatment, multiplicity, exploratory decisions and sensitivity checks. Use a suitable reporting convention, including APA format when requested, with enough numeric detail to reproduce the conclusion.

For before/after agent evaluation, match tasks, model, settings, tools and quality criteria; retain unsuccessful runs. Report task success and tokens per accepted task alongside costs. A smaller prompt alone does not establish lower total cost, better work or greater intelligence. Label historical snapshots separately from prospective measurements.
