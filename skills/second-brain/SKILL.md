# second-brain

Identify the target store and its source of truth. Read its local contract and reuse its structure; a database-backed store must not be silently converted to file authority. Capture-only requests preserve the original item without expanding it into a project.

For ingestion, preserve raw sources, record origin and content identity, and detect duplicates without deleting uncertain matches. For compilation, search existing pages first, cite source references and record conflicting evidence instead of silently overwriting it. Query with citations to the notes actually read and state coverage gaps.

For maintenance, identify broken links, missing provenance, duplicate pages, stale claims and oversized notes. Separate freshness from usefulness. Propose or apply authorized reversible cleanup with an undo record. Do not delete a known failure lesson simply because it is old.

New inferred preferences remain provisional; durable personal-memory updates require the user's explicit request and the host's memory rules. A task using notes does not authorize writing global memory. Verify changed files or records and preserve privacy boundaries.

Read [draft provenance and incorporated methods](references/draft-methods.md) when revising these methods.
