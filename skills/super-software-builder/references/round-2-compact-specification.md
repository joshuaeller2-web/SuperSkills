# Compact specification

For a vague or complex build request, capture five fields: Why, Capabilities, Constraints, Non-goals and Success signal. Give capabilities stable IDs when traceability helps. Record unresolved questions and link detailed supporting requirements rather than discarding them to fit the small template.

Scale to the task: a small fix need not become a full document. This method does not import BMAD's .memlog.md machinery, single-writer conventions, scripts or dependencies. Evaluate the implemented behavior against the user's original request as well as this specification.
