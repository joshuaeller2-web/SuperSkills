# Overlay titles

In a shadcn project, ensure Dialog, Sheet and Drawer have their corresponding meaningful title components. A visually hidden title can be appropriate when it remains available to assistive technology. Inspect actual component composition and rendered accessibility. This check complements project info and dry-run/diff previews; it is not full accessibility certification.
