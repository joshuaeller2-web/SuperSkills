# venture

Define buyer, paid problem, existing alternative and delivery unit. Compare actual alternatives, including what a general model can already do. A general model producing a useful answer is one competitive signal, not proof there is no business.

Estimate one delivery's tool cost, human time, review cost and capacity using explicit assumptions. Compare feasible price with cost and the buyer's alternatives. Inspect comparable competitor pricing, releases, reviews and hiring where relevant. Absence of advertising does not prove absence of demand.

Design the smallest experiment that can disconfirm the idea. State success, failure, stop date and spend boundary before a paid experiment. Distinguish interest from actual willingness to pay. Record rejected assumptions and what evidence could change the decision.

If staffing an agent workflow is requested, specify roles, review ownership, budgets and escalation before assigning work. Treat Paperclip or any adapter as an optional integration to verify, not an installed dependency. Pass an operating service to business-ops; a validation request does not authorize incorporation, purchases, outreach or deployment.
