## Resolved differences

1. Scripting, MCP, and UI operation remain conditional tools; each video demonstrates a particular environment, not a universal winner.
2. Abstract non-readable marks are suitable only for optional decorative imagery. Functional UI copy, diagram labels and informational overlays stay accurate and legible.
3. Concept images establish direction; native source, export checks, runtime use and physical fit establish different kinds of readiness.
4. Variant generation is bounded by the user's needs and resources. No automatic large batch, paid integration, or claimed savings.
5. The shared brief, semantic roles, representative slice, acceptance lanes, asset mapping and readiness vocabulary are local synthesis, not a method quoted from one creator.
